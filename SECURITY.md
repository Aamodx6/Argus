# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Nuance, please send an email to `security@warpyn.example` (or through our security portal).

Please include:
- A description of the vulnerability.
- Steps to reproduce or proof of concept.
- Potential impact and affected components.

We will acknowledge receipt within 24 hours and provide an estimated timeline for remediation. Please do not open public GitHub issues for undisclosed security vulnerabilities.
