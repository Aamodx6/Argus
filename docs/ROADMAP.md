# Nuance Roadmap

Planned features and platform enhancements for the Nuance multimodal video sentiment platform.

## Q1 2027: Multimodal Engine Expansion
- [ ] Real-time WebRTC streaming inference directly from client cameras.
- [ ] 12-class micro-expression detection (adding contempt, confusion, engagement, boredom, hesitation).
- [ ] Speaker diarization for multi-person video conference recordings.

## Q2 2027: Enterprise & Integrations
- [ ] Native Zoom, Google Meet, and Microsoft Teams app integrations.
- [ ] Enterprise SSO / SAML authentication via Neon Auth.
- [ ] Custom fine-tuning pipeline allowing workspaces to adapt models to domain-specific jargon.
- [ ] SOC 2 Type II audit report completion.

## Q3 2027: Developer Ecosystem
- [ ] Official Python and Node.js SDK npm/pip package releases.
- [ ] Asynchronous webhook dispatch for hour-long batch video files (> 1 GB).
- [ ] Granular team member role-based access control (RBAC).
